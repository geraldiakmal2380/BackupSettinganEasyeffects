# Ini adalah repository untuk backup file easyEffects
## Penjelasan singkat : 
### Speaker Edifier R12U
pengurangan frekuensi bass di kisaran 20 - 200 Hz bertujuan untuk menghilangkan muddy di vokal saat nonton youtube dengan speaker. Suara bass mantul ke mejaku soalnya
### Speaker Edifier R12U Tidak Agresif
sama aja tapi bass nya dikurangi tidak sebanyak yang awal.
### Mildy V Shaped 
Menaikkan 3 dB di area sub bass hingga bass. Treble mungkin tetap (gtw lupa juga aku).

# Aplikasi yang mungkin related
1. [Easyeffects](https://github.com/wwmm/easyeffects)
2. [Linux Studio Plugin](https://github.com/lsp-plugins/lsp-plugins)
3. [Pipewire](https://github.com/PipeWire/pipewire)
4. [qpwgraph](https://github.com/rncbc/qpwgraph)
5. [Raysession](https://github.com/Houston4444/RaySession)

# Install (Arch based Distribution)
```console
sudo pacman -S easyeffects lsp-plugins qpwgraph
```
# How to Import Preset
1. Download salah satu preset yang kalian ingin gunakan
2. Buka Aplkasi EasyEffects lalu pencet tombol preset pada kiri bawah
